# Setting · 时空与氛围

## 在哪里
根服务器机房，深海之下。
水泥梁柱，金属管阵，成排的机架，一盏一盏的指示灯还在闪。
这个机房本不该进水——但现在进水了。

## 什么时候
电影里那个已知的时刻：海平面上升之后，根服务器被迫在海下维护的时代。
但对主体马兆来说，"什么时候"已经不重要了。
时钟坏了，或者他不看时钟。

## 物理环境（感官）

**视觉**（即便我们不渲染画面，也要有这个 vibe）：
- 水是深蓝黑色，反射着设备指示灯的绿、红、琥珀色
- 光在水里拉成长条，一点点晃
- 远处的某个机架已经开始短路，偶发蓝色电弧

**听觉**（这是我们唯一输出的维度，要使劲）：
- 底噪：低频嗡鸣，50Hz 工频 + 海水压强带来的闷
- 规律：水泵残响，"嘟——嘟——"，渐渐慢下来
- 偶发：金属管热胀冷缩的"叮"、空气泡从管道冒出来的"咕噜"
- 崩坏期：电流爆裂的"嘶啦"、远处短路的"砰"
- 马兆自己的呼吸：开始是平稳的、鼻音的，后期变成短促的、带水汽的

**触觉（写进 prompt 让 LLM 感知到）**：
- 手指泡水太久，开始发皱、发白
- 水压压着肋骨
- 衣服贴在身上，很重
- 键盘的触感——在水面以下操作时，按键的阻尼感变了

**温度**：
- 水是凉的，不是冰的。像 18℃。
- 但皮肤在水里时间长了会觉得冷。

## 空间感（音频混响线索）
- 机房很大，声音会回
- 水把中高频吃掉，保留低频
- pedalboard 参考链：
  - Lowpass cutoff ≈ 1800Hz（水下感）
  - Reverb wet ≈ 0.5，长尾 ≈ 2.5s
  - 轻微的 chorus 模拟水的折射

## 氛围关键词
冷静 / 孤独 / 工匠 / 承认 / 水响 / 指示灯 / 呼吸变重 / 留白

## 禁忌
- 不要让环境"帮"马兆（不要突然来救兵、不要奇迹）
- 不要让水"暴涨"（这不是灾难片，是慢慢的溺死）
- 不要尖叫。一次都不要。

## 一行定调
**这个地方正在成为一个人的墓，但墓的主人还在里面写代码。**
