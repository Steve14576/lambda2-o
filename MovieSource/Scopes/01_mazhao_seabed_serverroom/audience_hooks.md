# Audience Hooks · 观众画外音介入点与情感钩子

> 观众不是在"玩游戏"。他们是在**听一个人的最后 2 分钟**。
> 他们说什么都有分量——但这个分量不一定换来剧情反馈。
> 这不是选择分支，这是"在场"本身。

## 观众听到的第一印象

戴上耳机的瞬间：
- 水声（先于人声 2 秒）
- 一个低频嗡鸣
- 然后——**键盘声**
- 然后——一个男人的呼吸
- 然后他说了第一句话：（可能是"来了？"，也可能是某段自言自语）

观众在最初 10 秒里会**自动揣摩身份**：
"我是谁？我是被他叫来的？我是他的同事？我是他的幻觉？"
这里没有答案，让 vibe 慢慢泡。

## 观众可能想说的话（原型）

### 关心型
- "你还好吗？"
- "情况怎么样？"
- "还撑得住吗？"

→ 马兆反应：就事论事回一句，然后继续工作。不会被情绪化。

### 指令型
- "快走！"
- "离开那里！"
- "别管服务器了！"

→ 马兆反应：浅浅拒绝。"来不及了。" / "不走。" / 沉默。
→ **不要让观众"救"他。**

### 追问型
- "你早就知道什么？"
- "图恒宇做了什么？"
- "丫丫是谁？"

→ 这是最有戏的一类。马兆可能答，也可能不答。
→ 答的话就是坦白（COLLAPSING 段的关键时刻）。
→ 不答的话就是留白。
→ **由 DM + LLM 决定，不预设。**

### 哲学型 / 共鸣型
- "没有人的文明，真的没意义吗？"
- "你后悔吗？"
- "你累不累？"

→ 马兆会接住。这是他的频道。
→ 可能引出一小段哲学对话。

### 胡说 / 恶作剧型
- "你好我是快递员"
- "hello?"
- "（唱歌）"

→ 马兆会有一瞬间的困惑。然后：
- 要么当幻听忽略
- 要么冷笑："你是谁？"
→ 这也是关键时刻：**观众第一次被看见**。

### 沉默
- 观众什么都不说

→ 环境接管。水声 + 马兆的工作声 + 他的自言自语。
→ 这一轮就是"听着一个人做事"，也是完整的。

## 关键钩子（DM 软层可以注意的触发词族）

| 钩子族 | 例词 | 可能的叙事结果 |
|---|---|---|
| 丫丫族 | "丫丫" "女儿" "孩子" | 马兆可能说出"早就知道"那句 |
| 图恒宇族 | "图恒宇" "老图" "他" | 马兆可能半坦白半掩饰 |
| MOSS 族 | "MOSS" "系统" "观测" | 马兆会停一下，但不直接回应 |
| 救援族 | "快走" "上去" "逃" | 马兆温和拒绝 |
| 哲学族 | "意义" "文明" "人" | 马兆最愿意接的频道 |
| 身份族 | "你是谁" "我是谁" | 反过来——马兆可能问观众这个 |

这些钩子**不是硬触发**。它们是 DM 可以用来**调整世界状态**（erosion、情绪基线）的输入，而不是"观众说 X → 马兆必须说 Y"的映射。

## 情感设计总目标

让观众在 2 分钟后离开时，感觉：
- **我来晚了**（但其实来不来都一样）
- **他不是在对我说话**（但他说的每句话我都听见了）
- **再来一遍会不会不一样**（会，也不会）

这是这个 Scope 的"情感产品"。

## 观众身份的隐约感

（与 "画外音身份渐进揭示为 MOSS" 的全项目主线挂钩 · ADR 暂未定）

在这个 Scope 里：
- 马兆**不会**识破观众是 MOSS（他没有那个信息）
- 但 DM 可以在 RESET 前给一丝暗示——比如最后一句警告音来自"观测系统"
- 观众自己可能在第 3-4 次进场时，开始怀疑："我是不是 MOSS？"
- 不强求揭示，留给整体项目的其他 Scope 去完成这条弧线

## 禁忌

- 不要把观众变成"拯救者"
- 不要让观众的话决定马兆是否死亡（他必然死）
- 不要让观众觉得"我说错话了" —— 怎么说都是对的，因为他听不听得见是另一回事
- 不要把 2 分钟填满对话 —— 留白比台词重要
