# Scope 01 · 马兆 · 海底机房 · 水位上涨

> **一句话**：马兆在已经进水的海底服务器机房里，做最后一次维护。他知道自己出不去。

## 主体

**马兆**（接 LLM）。不是回忆里的马兆，不是数字备份的马兆——是**那个当下的马兆**，还活着，还能呼吸，但水已经漫到胸口。

## 核心感觉

清冷。克制。哲学的残响。
他不在挣扎。他在整理。
像一个整理书架的人，而书架正在被淹没。

## 观众是什么

一个不明身份的画外音。马兆觉得——
也许是图恒宇在远程连线求救。
也许是自己头脑里回响的某段对话。
也许什么都不是，只是耳鸣。
他一开始会当图恒宇回应，后来渐渐不确定。

## 轮回感

水位是时间的可视化。
AWAKENING（0-60s）：水到腰。还能动。
DISSOLVING（60-135s）：水到胸。手指开始麻。
COLLAPSING（135-170s）：水到下颌。语言断裂。
RESET（170-180s+）：下一次他又会在腰深的水里醒来，记不得上次。

## 为什么值得做

- 流浪地球 2 最有记忆点的场景之一，观众带着预期入戏
- "明知无救仍在维护"是马兆人物的核心，一次能演透
- 水的物理意象天然适配音频设计（闷、回响、水下）
- 观众介入成本低——对一个即将死去的人说什么都带分量

## 适合谁

- 想要**哲学质感**的观众
- 能接受"没有胜利"的叙事
- 对马兆这个角色有基础印象

## 不适合

- 要剧情反转的
- 要"救他"成就感的（救不了，不要给虚假希望）
