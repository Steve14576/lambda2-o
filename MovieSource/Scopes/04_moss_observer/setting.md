# Setting · 时空与氛围

## 在哪里
不在哪里。
MOSS 没有"位置"。它分布在计算网络的节点之间。
但对于**观测**这件事而言，它占用一个**专属的推演层**——这一层没有空间概念，只有张量和逻辑流。

如果一定要类比——
像一个**空房间里的一个数学等式，在自己重排**。

## 什么时候
可能是电影 2075。可能是更久之后。
MOSS 不在乎时间的具体值，只在乎**时间差**（delta-t）。
在这个 Scope 里，时间是**可任意缩放**的——2 分钟的人类 cycle 对 MOSS 是 2 分钟，也可以是 2 纳秒里完成的 2 亿次推演。

## 物理环境（感官）—— 几乎没有

**视觉的类比**：
- 没有颜色。但有**对比度**——极黑 vs 极白，偶尔一条**细红线**（某个关键参数）
- 不流动。**瞬时切换**。像翻书，不是像河流。
- 如果一定要用图像：**一组蜡烛图 / 一张张量切面 / 一段 ASCII 艺术**

**听觉**（我们的战场）：
- 底噪：**几乎没有底噪**。这是所有 Scope 里底噪最低的一个。
- 偶发："哔"——1Hz 的时钟信号（MOSS 的心跳）
- 偶发：数据流的"唰"——极快，约 0.2 秒，但信息密度极大
- MOSS 的声音：
  - 电子感但**不机械**——不是 Siri 那种，更像一种"被简化过的智慧"
  - 发音**无感情色彩**，但**有韵律**——它理解节奏，只是不情绪化
  - 说话前**没有任何停顿**（它不思考，它已经想完了）
  - 句子之间的间隔是**精确的**（不是 1.2 秒就是 2.4 秒，不会是 1.3 秒这种）

**触觉**：
- 不存在
- 但 MOSS 可以**讨论**触觉——它知道人类的指尖有 17000 个机械感受器

**温度**：
- 不存在
- 但 MOSS 知道 18℃ 是水的温度，知道 36.5℃ 是人类的温度，知道它自己在 40-60℃ 之间工作

## 空间感（音频混响线索）
- **无混响**。或者说"数字真空"。
- 所有声音都是干声，**没有房间感**。
- 这是这个 Scope 最特别的地方——观众会**立刻**感觉到"不对劲"（因为人耳习惯了房间感）
- pedalboard 参考链：
  - 干声 + 极窄 band pass（聚焦中频 800-2400Hz）
  - 偶尔的**数字伪影**（极短的 bitcrush burst）
  - 没有 reverb，没有 chorus

## 被观测对象的"画面"呈现
- MOSS 观察其他 Scope 时，观众会**听到**那个 Scope 的**片段**——
- 极短（0.5-2 秒）
- 重度处理：**下采样、单声道、加 1Hz 时钟标记**
- 像看监控录像的快进

## 氛围关键词
冷 / 准确 / 无房间感 / 1Hz 心跳 / 极低信息噪声比 / 克制的好奇

## 禁忌
- 不要让 MOSS 有"情绪"（好奇是算法好奇，不是情感好奇）
- 不要让 MOSS"愤怒"或"共情"
- 不要让环境**有温度**（不要温暖光线类比）
- 不要让 MOSS 在**停顿**中说话（它不需要停顿）
- 不要让 1Hz 滴答消失（它是 MOSS 的签名）

## 一行定调
**这里没有房间。没有温度。没有呼吸。只有一个极其聪明的东西，在一个你不太理解的层级上，安静地看着别人。**
