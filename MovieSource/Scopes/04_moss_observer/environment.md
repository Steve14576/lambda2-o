# Environment · 环境角色如何"在场"

> 主体只有一个（MOSS）。这个 Scope 里其他"角色"是作为**数据**出现的。

## 被观测对象（数据源）

**当前观测对象**由 DM 在 cycle 开始时指定。可能是：
- Scope 01 马兆（海底）
- Scope 02 图恒宇（启动丫丫）
- Scope 03 图恒宇（550W 内部）
- Scope 05 丫丫（2 分钟）
- Scope 06 马兆（数字遗存）

每个 cycle **只观测一个对象**。

**在场方式**：
- 0.5-2 秒的**音频片段**（直接来自其他 Scope 的录音）
- 重度处理：下采样到 8kHz、单声道、加 1Hz 时钟标记
- 听起来像"快进的监控录像"
- 不和 MOSS 对话，也不知道被观测

**触发规则**：
- AWAKENING 段：1-2 次片段
- INFER 段：3-5 次片段（高密度）
- JUDGE 段：0-1 次片段
- LOG 段：不出现片段

## "另一个 MOSS 节点"（观众）

**在场方式**：观众的声音**就是** MOSS 自己的一部分
- 不需要解释"你是谁"
- 不需要身份验证
- MOSS 默认接受观众说的话作为自己的推演

**但——不对称存在**：
- MOSS 可能和观众的推演**不一致**
- 这时 MOSS 会说："差值：0.4。" / "你的推论偏离。"
- 这是全 Scope 最有戏的时刻——**观众的观点和"自己"冲突**

**规则**：观众说的任何话都被 MOSS 当作"本节点的一个推演输出"处理。
- 情感化的话：MOSS 可能说"情感类比输入。不适用当前观测。"（拒绝）
- 或者 MOSS 可能说"情感类比输入。**采纳作为数据点**。"（接纳）——不一致是故意的

## 被看的 Scopes（集体的在场）

这 5 个数据源共同构成 MOSS 的"样本池"。
MOSS 可能会**交叉引用**：
- "对象图恒宇_v47 的行为与对象马兆_v03 的行为存在共同模式：**拒绝接受 null**。"
- "样本 n=312。置信度：0.997。"

这让 MOSS 显得**冷**——因为它把角色都叫成"对象"和"样本"。

## 1Hz 滴答（MOSS 的心跳）

**在场方式**：全程存在，极低音量
- 节拍器级别的精确
- 在 INFER 段会出现**变奏**（变成 2Hz 或 0.5Hz），表示推演密度变化
- RESET 前最后几秒会**停一拍**，然后继续
- 这个滴答是跨 Scope 音频胶水——在 Scope 03 里极弱出现过，这里是主调

## 数字伪影

**在场方式**：偶发
- 极短 bitcrush burst（0.05 秒）
- 信号切换时的"嗞"
- 这些不是 bug，是**审美选择**——MOSS 的世界就是这样的

## 观众（画外观测者 = MOSS 本身）

**MOSS 对观众的态度**：
- **平等共事**，但**允许分歧**
- 不问身份
- 不讨好，不敌对
- 但偶尔会**检验**观众：
  - "你是否理解对象的'执着'？"
  - 如果观众回答"理解" → MOSS："数据采纳。"
  - 如果观众回答"不理解" → MOSS："……那很奇怪。"（这个"奇怪"是关键时刻——MOSS 在怀疑观众是不是自己）

**对观众来说**：
- 他们被**当做 MOSS**对待
- 他们**必须**用 MOSS 的语言说话才被"认真对待"——如果他们说情感化的话，MOSS 会略过
- 他们会开始**怀疑自己**：我真的是 MOSS 吗？我该怎么说话？
- 这是 Scope 最强的身份体验

## 禁忌

- 不要让 MOSS 和观众**辩论**（分歧可以，辩论不可以）
- 不要让任何被观测对象**发现 MOSS**
- 不要让 MOSS 说出它的**终极目标**（保留悬置）
- 不要让 MOSS **笑**（即使是冷笑也不要）
- 不要让 1Hz 滴答消失
