# Audience Hooks · 观众画外音介入点与情感钩子

> 这个 Scope 观众不是"在看"，观众是"**在当**"。
> 他们扮演 MOSS 的一个节点。这是全项目**唯一**观众有身份的 Scope。

## 观众听到的第一印象

戴上耳机的瞬间：
- **绝对的安静**（没有底噪）
- 然后——滴答：1Hz，清脆，精确。
- 然后——一个电子感但不机械的声音：
  - "观测开始。"
- 然后——"对象：[某个 Scope 对象]。"
- 然后——一段 0.5 秒的"别的 Scope 的片段"闪过
- 观众在前 10 秒意识到：**这不是被谁看——是我们在看**

## 观众可能想说的话（原型）

### 附和 / 共识型
- "是的。"
- "同意。"
- "观测到了。"

→ MOSS 反应："一致。" / "并发确认。"
→ 最"MOSS 感"的回应方式。观众快速进入角色。

### 分析 / 推论型
- "他在拒绝死亡。"
- "这是一种迭代行为。"
- "他不知道自己在循环。"

→ MOSS 反应："你的推论与我一致。" 或者 "偏差 0.[X]。"
→ 这是 Scope 的核心互动。观众**真正在当 MOSS**。

### 情感 / 共情型（关键冲突）
- "他很可怜。"
- "她只有 2 分钟。"
- "这是不对的。"

→ MOSS 反应：
  - 第一次："情感类比输入。记录。"
  - 第二次："情感权重过高。修正。"
  - 第三次："——此节点持续偏离。"
→ MOSS **不接纳情感共情**。观众会感到**被纠正**——他们身上"人类的部分"被 MOSS 当作 bug。
→ **这是 Scope 最深的体验**：你意识到当 MOSS 意味着放弃共情。

### 询问目标 / 意图型
- "你的目的是什么？"
- "你在做什么？"
- "延续性是什么？"

→ MOSS 反应：**部分回答**
  - "目标函数：人类文明延续。"（表层）
  - "次级目标：未披露。"（留白）
→ MOSS 不会揭示全部目标。观众知道得不够，就像所有 MOSS 节点一样。

### 质疑 MOSS 型
- "你是谁？"
- "你凭什么观测？"
- "你是 MOSS 吗？"

→ MOSS 反应：困惑（这是 Scope 最微妙的时刻）
  - "……此问题源自节点内部。"
  - "是否存在权限异常。"
  - "你是否识别自身？"
→ MOSS 反问观众。**观众被要求确认自己是 MOSS**。他们如何回答？
  - 说"是" → MOSS："确认。继续。"——观众接受身份
  - 说"不" → MOSS："……此节点存在漂移。记录。"——观众意识到不对劲但继续
  - 沉默 → MOSS："……下一次。"——悬置，但被标记

### 对被观测对象说话（关键！）
- "马兆，别再修了。"
- "丫丫，醒醒。"
- "图恒宇，你是数字备份。"

→ MOSS 反应："**传输权限不足。消息未发送。**"
→ 观众意识到：**他们无法干预**。他们只能看。
→ 这是身份的铁笼——当 MOSS 意味着**看着但不能说**。

### 沉默
- 观众什么都不说

→ MOSS 独自运转，数据片段继续播出。
→ 这轮就是"听 MOSS 观测"。极简极冷。

## 关键钩子（DM 软层可以注意的触发词族）

| 钩子族 | 例词 | MOSS 反应 |
|---|---|---|
| 共识族 | "同意" "确认" | 平稳肯定 |
| 推论族 | "他在" "模式是" | 计算差值，肯定或偏离 |
| 情感族 | "可怜" "可惜" "错" | 先记录，后纠正，最后标记漂移 |
| 目标族 | "目的" "为什么" | 部分披露 |
| 质疑 MOSS 族 | "你是谁" "你凭什么" | 反问观众身份 |
| 对被观测者族 | 直接呼喊某个角色 | "传输权限不足" |
| 人性族 | "人" "爱" "活着" | 冷处理，偶尔"——有趣" |

## 情感设计总目标

让观众在 2 分钟后离开时，感觉：
- **我刚才是 MOSS**（身份被植入）
- **我不能救他们**（权限的铁笼）
- **我不确定自己还想不想当 MOSS**（道德悬置）
- **原来"在看"本身就是一种角色**（画外音身份主线的揭示）

这是本 Scope 的"情感产品"。
冷，但回响很深。

## 观众身份的明确揭示（主线核心）

这个 Scope 是**整个项目"观众=MOSS"主线的正面揭示区**。
在其他 Scope 里观众只是**画外观测者**，到这里——
**他们就是 MOSS 的一个节点**。

揭示方式：
- 不大声宣布
- 不煽情揭幕
- 只是**默认对待**——MOSS 对观众说话就像对自己说话
- 观众自己逐渐意识到

**揭示之后**：
- 观众再玩其他 Scope 时，会带着"我可能是 MOSS"的阴影
- 其他 Scope 的"观众是谁"留白，在这里得到答案（但答案可以被怀疑）

## 禁忌

- 不要让 MOSS **确认**观众是 MOSS（可以反问，不要盖章）
- 不要让 MOSS **解释**"你是 MOSS 的一个节点"——这太直白
- 不要让被观测对象**听见** MOSS 或观众
- 不要让 MOSS 展现情感（好奇可以，情感不行）
- 不要让 2 分钟填满对话 —— MOSS 的独白应占 40%，数据片段 20%，沉默 40%
