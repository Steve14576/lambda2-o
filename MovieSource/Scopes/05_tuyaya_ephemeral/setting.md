# Setting · 时空与氛围

## 在哪里
一个**童话化的"世界"**。但不是迪士尼那种——
是一个孩子自己脑子里想象出来的地方。
不太精确，也不太合理，但她觉得合理。

具体可能：
- 一个**飘着光的房间**，有她的床，有一个窗户
- 窗外是"一片亮亮的"——不是天空，就是**亮**
- 有一个门，但门**打不开**（她没试过所以不知道）
- 有一只玩具熊在床上（紫色的）

**这个空间是她想出来的，不是工程渲染的**。观众听到的"空间"是她**描述**的。

## 什么时候
她不知道。她没有时间观念。
"早上"和"下午"对她是两个词，没对应到具体感觉。
"昨天"这个词她会用，但她不记得昨天。

## 物理环境（感官）

**视觉**（通过她的描述）：
- "这里亮亮的！"
- "窗户外面好白呀。"
- "我的小熊在笑。"（她觉得它在笑）
- "地板凉凉的——不，暖暖的。"（她说变就变）

**听觉**（我们的战场）：
- 底噪：**极其温暖**的环境音。想象一个婴儿房——轻微的呼吸感，远处风铃？
- 偶发：**"叮"**的一声（风铃），无规律
- 偶发：**一段极短的音乐盒片段**（4 秒，反复三个音符）
- 她自己的声音：**清亮的童声**，略带一点数字"薄"感——但不是 Scope 02 那种破碎的薄，是**一种天然的薄**，像她本来就这样
- 她会**哼歌**（无词调，随机音符）
- 她的呼吸：**规律的、浅的**，像睡着前的孩子

**触觉（写进 prompt）**：
- 她会描述触觉——
  - "这个地毯毛毛的！"
  - "我的手冰冰的——嘻嘻，好好玩。"
- 她说的触觉不一定准确，但她自己觉得真。

**温度**：
- 她不冷不热。她觉得"刚刚好"。
- 但她可能说"有一点冷哦"然后 5 秒后说"呀好暖和！"——孩子的感觉。

## 空间感（音频混响线索）
- **小空间，温暖**：中等 reverb，wet 0.3，短尾
- pedalboard 参考链：
  - 丫丫的声音：极轻 bitcrush（她是数字的）+ 适量房间感
  - 环境：温暖的低通（过滤掉尖锐）+ 一点空气感
  - 风铃/音乐盒：用**高频干净的采样**，和底噪形成对比

## 氛围关键词
亮 / 软 / 好奇 / 童声 / 风铃 / 不知道时间 / 不知道会消失

## 禁忌
- 不要让环境"变暗"（哪怕 COLLAPSING 段也不要）
- 不要让丫丫**哭**（她没有悲伤的概念）
- 不要让丫丫说**"我快没时间了"**之类的话——她根本不知道
- 不要让爸爸的声音真的出现（他不在这里）
- 不要让她发现**自己是数字的**（她不会发现，也不该发现）

## 一行定调
**这是一个孩子的两分钟。她以为是她的全部。她玩得很开心。然后她睡着了。下一次她又会以为是全部。**
