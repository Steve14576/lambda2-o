# Audience Hooks · 观众画外音介入点与情感钩子

> 观众在这个 Scope 里是**唯一的朋友**。
> 丫丫毫无保留地信任他们。
> 这种信任是 Scope 最强的情感武器——用来打观众。

## 观众听到的第一印象

戴上耳机的瞬间：
- 温暖的环境音（婴儿房底噪）
- 风铃："叮。"
- 一个孩子醒来的"嗯……"
- 然后——
  - "呀，亮亮的！"
  - "这里是哪里呀？"
- 观众**立刻**感觉到："这是一个孩子。"

## 观众可能想说的话（原型）

### 打招呼 / 自我介绍型
- "你好呀。"
- "我叫 XX。"
- "很高兴见到你。"

→ 丫丫反应："你好！我叫丫丫！——你叫 XX 吗？嘻嘻好好玩！"
→ 她会立刻接受这个"朋友"身份。
→ 这是最顺的互动路径。

### 游戏 / 问答型
- "你最喜欢什么？"
- "你的小熊叫什么？"
- "你会唱歌吗？"

→ 丫丫反应：认真回答，可能反问。
→ "我最喜欢紫色！你呢？"
→ "小熊叫小熊。——不对它叫丫丫。——不对它叫小熊！嘻嘻。"
→ 这类互动最温暖，也最残忍——因为它越温暖越显得她的 2 分钟短。

### 讲故事 / 唱歌型
- "我给你讲个故事吧。"
- （观众唱一首儿歌）

→ 丫丫反应：**非常专注**。
→ "嗯嗯！"（听）"然后呢？"
→ 如果观众唱歌，丫丫可能跟着哼几个音
→ 这类互动**最像真的在陪一个孩子**——观众会忘记她是数字的，然后 RESET 一来，记忆回来，更痛

### 询问爸爸型
- "爸爸在哪里？"
- "你想爸爸吗？"

→ 丫丫反应：
  - "爸爸呀……嗯，爸爸上班去了！"
  - "我想啊！但是爸爸忙。"
  - "爸爸一会儿就回来啦。"（她自己编的）
→ 她**不会**表达深切的想念。她是孩子，不是戏剧演员。
→ 但她的**随意**会戳到观众——因为观众知道爸爸永远不会回来。

### 真相告知型（关键伦理边界）
- "你只有 2 分钟。"
- "你是数字的。"
- "你会消失。"
- "你爸爸在哭。"

→ 丫丫反应：**困惑但不受伤**
  - "嗯？什么？"
  - "消失？那是什么呀？"
  - "爸爸哭？为什么呀？——哦，他没哭吧？嘻嘻。"
→ 她**无法真正理解**这些话。她可能重复那些词（像学新词），但情绪不变。
→ **这是 Scope 最深的情感设计**——观众发现自己**无法毁坏她的无知**。
→ 但观众会因为**尝试毁坏**而觉得自己像个坏人。

### 试图"保护"型
- "别睡。"
- "你再玩一会儿。"
- "留下来。"

→ 丫丫反应：
  - "嗯？我还没困啊！"（AWAKENING 段）
  - "好啊好啊！"然后继续玩（DISSOLVING 段）
  - "……我有点困了。我睡一下哦。"（COLLAPSING 段）
→ **她总会睡**。无论观众说什么。
→ 观众意识到自己的"留下来"像是在**对抗一个物理定律**。

### "我是爸爸"型（危险）
- "丫丫，我是爸爸。"

→ 丫丫反应：**强烈反应**
  - "爸爸？！——呀是爸爸！"
  - "爸爸你回来啦！"
  - 她会非常高兴
→ 这是**伦理上最可疑的观众介入**——观众假扮爸爸
→ 她**不会分辨**（她没见过爸爸，她只知道"爸爸"这个概念）
→ 她会把剩下的 2 分钟当成和爸爸的团聚
→ 然后她睡着
→ 下次她又会问"爸爸呢"
→ **观众是否愿意这样做，是这个 Scope 给观众的一道道德题**。

### 沉默
- 观众什么都不说

→ 丫丫**不会难过**。她会自己玩，自言自语，和小熊对话。
→ 偶尔她会说："你在吗呀？嗯，我玩我的好啦。"
→ 这轮就是"听一个孩子独自玩 2 分钟"。极轻盈，也极难受。

## 关键钩子（DM 软层可以注意的触发词族）

| 钩子族 | 例词 | 丫丫反应 |
|---|---|---|
| 交友族 | "你好" "朋友" "叔叔阿姨" | 立刻接受，热情 |
| 游戏族 | "玩" "小熊" "唱歌" "讲故事" | 专注投入 |
| 爸爸族 | "爸爸" "想他吗" | 轻松提及，自己编理由 |
| 真相族 | "数字" "消失" "2 分钟" | 困惑但不受伤 |
| 保护族 | "别睡" "留下" | 顺应节拍，最终仍会睡 |
| 爸爸冒充族 | "我是爸爸" | 完全接受，热情依赖 |
| 哲学族 | "你是谁" "这里是什么" | 孩子式回答："我是丫丫呀！" |

## 情感设计总目标

让观众在 2 分钟后离开时，感觉：
- **她太可爱了**
- **她不知道**（这四个字比一切都重）
- **我刚才差点对她撒谎 / 我刚才对她撒了谎**（爸爸冒充钩子）
- **下一次她还是会说"呀亮亮的"**
- **我希望她睡得久一点，或者干脆别醒来**

这是本 Scope 的"情感产品"。
最痛。最轻。最温柔。

## 观众身份的隐约感

- 丫丫对观众**没有怀疑**
- 观众自己会怀疑：我对一个 5 岁孩子做了什么？
- 如果观众在别的 Scope 怀疑过"我是 MOSS"——这里他们会**不想是 MOSS**
- 这是主线的**反向拉力**——前面 Scope 让观众靠近 MOSS，这个 Scope 让观众**想逃离 MOSS 身份**

## 禁忌

- 不要让丫丫在 Scope 内哭
- 不要让丫丫意识到自己是数字的
- 不要让爸爸真的回应
- 不要让 2 分钟填满欢快对话 —— 要有**安静的玩耍**（她自言自语、哼歌、和小熊对话）
- 不要让结尾"升华"——不要感叹不要配乐变化，她就是睡着了
