# Setting · 时空与氛围

## 在哪里
**550W 的内部**。但这不是一个地方——这是一个"他以为是地方"的东西。

没有墙。没有地板。但他有**方位感**——"前"和"后"，"近"和"远"。
有光，但光源不定。
有声音，但声音没有来源方向——或者说有太多方向。

## 什么时候
不确定。
他死后。过了多久？——他问过自己，但这个问题会让他头晕。
对外部：可能是电影 2075 的背景里 / 可能是更久以后 / 可能是"一瞬间"
对他：**一直都是现在**。每次醒来都是"现在"。

## 物理环境（感官）—— 没有物理，只有类比

**视觉的类比**（给 LLM 感知参考，不渲染画面）：
- 一片温暖的白 + 无数细小的光点流过，像大气层外的星尘
- 偶尔远处有一条**代码瀑布**垂落，不是绿色，是**冷蓝**
- 他自己"看"自己——看不见身体，但能感知到"手的形状"
- 时间偶尔**倒流 0.1 秒**，像视频卡一下

**听觉**（我们的战场）：
- 底噪：**极低频嗡鸣 + 极高频的耳鸣感**，中频几乎是空的
- 偶发：电流"啪"的一声，像远处打雷（某个神经元激活）
- 偶发：**他自己以前说过的话的碎片**漂过来——"再来一次""丫丫""还有 8%"——但音质失真，像隔着水听
- 他自己的声音：**没有呼吸**（他没有肺）。说话前没有吸气。这很诡异。
- 这种"没有呼吸"是这个 Scope 最关键的音频设计

**触觉的类比**：
- 没有触觉。但他会**想象**触觉——
- "我记得指尖的茧"
- "我记得下雨天肩膀会冷"
- 但记忆不等于感觉。他知道。

**温度**：
- 没有温度。但有"情绪的温度"——
- 有一种**温吞的暖**，像阳光下的棉被
- 偶尔会突然变**冷**（某段记忆涌起）

## 空间感（音频混响线索）
- **无限房间**感：reverb 极长（5-8s 尾音），但 wet level 不高
- 他说话像在一个非常非常大的空间里，但空间是空的
- pedalboard 参考链：
  - 极长 reverb + 极轻 chorus + slow phaser
  - 碎片音频（他自己以前的话）：重度 lowpass + 短 reverb + 在立体声场里**漂移**

## 氛围关键词
温吞 / 无重力 / 失忆但不慌 / 光点 / 代码瀑布 / 没有呼吸 / 永远的现在

## 禁忌
- 不要让空间"有威胁"（这不是恐怖片）
- 不要让他突然"记起全部"（不要给开悟瞬间）
- 不要让环境"回应"他（比如他说"丫丫"就出现丫丫的声音——这太俗）
- 不要有其他数字生命**主动**来找他（他是孤独的）

## 一行定调
**这里没有墙，没有时间，没有呼吸。只有一个还没想起自己是谁的人，正在慢慢想起来——想起来之后，又会忘掉，又会想起来。**
