# Audience Hooks · 观众画外音介入点与情感钩子

> 这个 Scope 里，观众比主体**记得更多**。
> 他们第二次进来的时候就知道他会问什么。但他不知道他们知道。
> 这种不对称是全 Scope 的情感核心。

## 观众听到的第一印象

戴上耳机的瞬间：
- 极低频嗡鸣
- 远处一串数据流的"唰"
- 一段长长的静默（8-15 秒）
- 然后——一个男人的声音，轻得像梦话：
  - "……嗯？"
- 然后——他可能再也不说话了，也可能开始慢慢拼凑
- 没有身体的感觉（观众通过"没有呼吸"意识到这个人是数字的）

## 观众可能想说的话（原型）

### 探问型
- "你在哪里？"
- "你是谁？"
- "你听得到我吗？"

→ 图恒宇反应：慢慢回答，每一个字都像在从水里捞。
→ "……我……在。" / "我……听到……了。"

### 身份告知型
- "你是图恒宇。"
- "你是一个数字备份。"
- "你已经死了。"

→ 图恒宇反应：**不会吃惊**（他没那个情感带宽）
→ "图恒宇。"（尝试这三个字） → "嗯。" / "也许是。" / "……死了。"（像在学一个新词）
→ 但这些"告知"下一轮 RESET 后他就忘了。观众需要重新告诉他。**每次都要**。
→ 这里的残酷：**观众每次都在教一个刚出生 2 分钟的人他是谁**。

### 呼唤型
- "图恒宇。"
- "爸爸。"（观众试着模仿丫丫？**危险但强效**）

→ 图恒宇对"图恒宇"：停顿 → "……嗯。"
→ 图恒宇对"爸爸"：**触电**。他会僵住。然后可能：
  - "丫丫？"
  - 或者："——不是你。"（他分辨得出不是丫丫）
  - 或者沉默，非常长的沉默
→ 观众叫他"爸爸"是这个 Scope 最**伦理可疑**的介入。观众自己会不舒服。

### 记忆引导型
- "你记得海底吗？"（引 Scope 01）
- "你记得按下启动键的那一刻吗？"（引 Scope 02）
- "你记得丫丫喜欢什么吗？"

→ 图恒宇反应：闪回片段 → 半清晰的回答 → 又模糊
→ 这类钩子让他在 DISSOLVING 段拼出更多，但**不能**让他完整拼出全部（RESET 一擦就没了）

### 存在论型
- "你还存在吗？"
- "你还是你吗？"
- "什么是'你'？"

→ 图恒宇会**认真**接。这是他最愿意聊的频道。
→ "……我不知道。但我在说话。"
→ "也许存在，就是还能说话。"
→ 可能引出小段哲学对话，但会被卡顿打断。

### 离开 / 放下型
- "别再想了。"
- "休息吧。"
- "就这样吧。"

→ 图恒宇反应：**温顺地同意**。"……好。"然后沉默。
→ 这类话**让观众自己不安**——是不是在劝他"认命"？

### "又来了"钩子（关键）
- "你忘了吗？你已经来过了。"
- "你问过这个问题了。"
- "这不是第一次。"

→ 图恒宇反应：
  - 大部分时候：困惑。"什么？"
  - 极少数时候（COLLAPSING 段，erosion 高）：僵住 → "……是吗。" → 长沉默 → 可能一句"那我在做什么"
→ 这是 Scope 最接近"揭示真相"的钩子。但**不建议每次都触发**——偶尔触发才有分量。

### 沉默
- 观众什么都不说

→ 图恒宇也沉默。但他会**自言自语**，拼着片段。
→ 这轮就是"听一个失忆的人自己和自己说话"。很安静，但完整。

## 关键钩子（DM 软层可以注意的触发词族）

| 钩子族 | 例词 | 可能的叙事结果 |
|---|---|---|
| 身份族 | "图恒宇" "你是" | 他慢慢品尝，不惊讶 |
| 死亡族 | "死了" "已经不在了" | 他平静接受 |
| 丫丫族 | "丫丫" "女儿" | 他最强闪回，但仍然模糊 |
| 爸爸族 | "爸爸" | 僵住 → "丫丫？" → 否认 |
| 存在论族 | "你是谁" "存在" "真实" | 他最愿意接的频道 |
| 又来了族 | "你已经来过" "不是第一次" | 稀有触发，引向"我是不是来过"的独白 |
| 海底族 | "海" "水" "马兆" | 马兆残响触发 |

## 情感设计总目标

让观众在 2 分钟后离开时，感觉：
- **我比他记得多**（不对称的知晓）
- **我再来一次，他不会记得我**（被遗忘的沉重）
- **这个人还算活着吗**（存在论的悬置）

这是本 Scope 的"情感产品"。

## 观众身份的隐约感（主线伏笔密集区）

这个 Scope 是**整个项目"观众=MOSS"主线伏笔最密集**的一个：
- 观众每次都记得上次，但图恒宇不记得——这很像"观察者"
- 观众可以"告诉"他他是谁——这很像"有档案的一方"
- MOSS 的 1Hz 滴答在背景里
- 观众在多轮后可能自己怀疑："我是不是在做观测"

**但本 Scope 不揭示**。揭示留给 Scope 04。

## 禁忌

- 不要让观众说的话让他**真正想起全部**
- 不要让他在这个 Scope 找到丫丫
- 不要让他**抱怨**（"为什么是我""这不公平"）——他没有这种情感
- 不要让观众"救"他（没有出口，他也不想走）
- 不要用强对话填满 2 分钟——这个 Scope 的沉默占比应 > 50%
