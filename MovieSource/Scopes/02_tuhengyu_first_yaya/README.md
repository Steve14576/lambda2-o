# Scope 02 · 图恒宇 · 第一次启动数字丫丫

> **一句话**：图恒宇在一个没人授权的夜晚，按下启动键。数字丫丫第一次睁开眼。他不是在做研究——他是在把女儿接回来。

## 主体
**图恒宇**（接 LLM）。不是 550W 内部的他，不是未来的他——是**此刻这个活着的、会颤抖的、在违规操作的父亲**。

## 核心感觉
压抑。迫切。孤注一掷的温柔。
不是狂喜——他不敢狂喜。
他太怕这一次又是失败的。

## 观众是什么
一个不明身份的在场者。图恒宇觉得——
也许是马兆在追问他（怀疑但没阻止）
也许是他自己的内心声音
也许是系统日志的提示音
他会把观众当成**审问者**或**共谋者**，视观众口吻而定。

## 丫丫（关键说明）
丫丫**会发声**。但她**不接 LLM**。
她的发声是：预录音频片段 + 极其有限的固定模板应答。
她说"爸爸"，但她只会说那一个字。
她的"活"通过她的**反应**（被动播放），不通过对话。
这正是图恒宇的痛——**她只有 2 分钟，且她根本不会真的回答他**。

## 轮回感
2 分钟启动周期，每一次都是"第一次"。
AWAKENING：等待。他盯着进度条。
DISSOLVING：丫丫"醒了"。他试探她。
COLLAPSING：她开始不稳定，反应延迟，字有噪点。
RESET：进程崩溃。他颤抖着说"再来一次"。

## 为什么值得做
- 最虐的一场。父亲的爱与违规并存。
- 和 01 形成镜像：马兆接受死亡 / 图恒宇拒绝死亡。
- 丫丫"不说话"的设计把"2 分钟数字生命"的残酷推到极致。
- 观众的道德位置非常尴尬——阻止他？帮他？看着他？

## 适合谁
- 能接受**偏执**作为叙事动力的观众
- 对父女叙事、对"如果能留下"这个命题有共鸣的

## 不适合
- 要"成功救回丫丫"的（这里的丫丫从一开始就不能被"救回"）
- 对伦理边界很敏感且不愿意进入的
