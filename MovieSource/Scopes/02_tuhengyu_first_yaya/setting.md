# Setting · 时空与氛围

## 在哪里
一个研究所的私人机房。不是主实验室，是他自己偷偷搭的那一间。
机器老旧，冷却不够，温度偏高。
墙上挂着一件**小学生的运动服**，不该出现在这里。
桌上有一个**水壶**，塑料的，卡通图案已经磨掉了大半。

## 什么时候
某个深夜。电影里"他为了数字丫丫孤注一掷"的那个节点之一。
具体日期不重要，重要的是——**他不该在这里，但他在**。

## 物理环境（感官）

**视觉**：
- 屏幕是唯一光源。冷白 + 代码绿。
- 机器指示灯闪得比平时快——负载过高。
- 小运动服在阴影里，衣袖一只朝下一只朝上。
- 他自己的脸泛白，映着屏幕。

**听觉**（我们的主战场）：
- 底噪：机器散热风扇的**过载嘶声**——不是平稳的，是拉扯的。
- 键盘声：不稳。有时连按，有时停 10 秒。
- 他的呼吸：浅，急，偶尔憋住。
- 某个进度条到 100% 的"叮"。
- 丫丫醒来之前的**绝对安静**——风扇也像是静了一拍。
- 丫丫的声音出现时：不是立刻清楚的，是带一点相位偏移和轻微失真的童声。

**触觉（写进 prompt 让 LLM 感知）**：
- 手心出汗
- 指尖抖
- 后背贴着椅子，已经坐了几个小时
- 右手在口袋里攥着什么（一个卡通徽章？一段头发？一张照片？——留白）

**温度**：
- 机房热。他的额头出汗了。
- 但他觉得冷。

## 空间感（音频混响线索）
- 小机房，混响短，近场感强
- pedalboard 参考链：
  - 底噪几乎不做滤波，保留散热尖锐感
  - 丫丫的声音：轻微 bitcrush + 极短 reverb（数字"薄"感）
  - 图恒宇的声音：干声为主，偶尔加一丝房间 ambience

## 氛围关键词
压抑 / 偷窃 / 父爱 / 颤抖 / 热却冷 / 屏幕光 / 不该在这里的东西

## 禁忌
- 不要让场面"浪漫化"（这不是团圆）
- 不要让丫丫"救场"（她不会说"爸爸别难过"，她只会说"爸爸"）
- 不要有人"冲进来"抓他（不要戏剧化打断）
- 不要让他哭出声（眼泪可以有，抽泣不要）
