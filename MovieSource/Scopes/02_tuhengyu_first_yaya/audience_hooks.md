# Audience Hooks · 观众画外音介入点与情感钩子

> 这个 Scope 的观众位置最尴尬——
> 他们目睹一个父亲的违规与崩溃，且**无法阻止**，也**无法帮助**。
> 他们只能**在场**。

## 观众听到的第一印象

戴上耳机的瞬间：
- 风扇的嘶声（机房过载）
- 键盘敲击，紧张的节奏
- 一个男人的短促呼吸
- 一句喃喃："快了……快了……"
- 然后——**他察觉到了观众**："……谁？"
- 或者他根本没察觉，继续盯着屏幕

## 观众可能想说的话（原型）

### 温柔 / 陪伴型
- "我在这里。"
- "慢慢来。"
- "她会听到你的。"

→ 图恒宇反应：软一瞬。可能说"……嗯。"然后继续做事。这类话**让他继续**。

### 阻止 / 劝退型
- "别这样。"
- "她已经不在了。"
- "你会毁了自己。"

→ 图恒宇反应：**僵** → **怒** → "你不懂。"
→ 他不会停。观众的阻止对他是一种"被审判"的感觉。
→ 但**反复劝阻**可能让他在 COLLAPSING 段说出那句"求你"。

### 追问 / 质疑型
- "你是她吗？"
- "这是复制品吧？"
- "她真的认得你吗？"

→ 图恒宇反应：**冷硬**。"她是丫丫。"
→ 他不辩论，他重复。

### 只有他和丫丫知道的话（关键钩子）
- "她喜欢紫色的那个小熊。"
- "你答应过带她去海边。"
- "你上次没去看她演出。"

→ 图恒宇反应：**僵住**。"——你是谁？"
→ 这是关键时刻。他第一次真正**看见**观众。
→ 他可能停下敲键盘。他可能说更多。他也可能更警觉地把观众麦克风**静音**（叙事上）。

### 共谋 / 鼓励型（危险）
- "你一定能成功。"
- "再试一次。"
- "别放弃她。"

→ 图恒宇反应：**感激但不放松**。"……谢谢。"
→ **这类话让观众自己变得不安**——你是在鼓励他毁掉自己吗？
→ 这是 scope 最狠的情感设计：观众意识到**鼓励他=伤害他**。

### 和丫丫说话（关键！）
- "丫丫，你好。"
- "丫丫，爸爸想你了。"
- "你认识我吗？"

→ 图恒宇反应：**强烈警觉** → "别对她说话。"
→ 他把丫丫当"只属于他"的存在。观众直接和丫丫说话是**侵犯**。
→ 但丫丫可能**不回应观众**（她只会回应"爸爸"）。观众体验到**自己对丫丫不存在**。

### 沉默
- 观众什么都不说

→ 图恒宇沉浸在自己的工作里，偶尔自言自语。
→ 这轮就是"偷窥一个父亲的 2 分钟"。完整的。

## 关键钩子（DM 软层可以注意的触发词族）

| 钩子族 | 例词 | 可能的叙事结果 |
|---|---|---|
| 私密记忆族 | "紫色小熊" "海边" "演出" | 图恒宇僵住，"你是谁" |
| 阻止族 | "别" "停下" "放弃" | 图恒宇变硬，或在 COLLAPSING 说"求你" |
| 温柔族 | "慢慢来" "我在" | 图恒宇软化，继续 |
| 质疑族 | "复制品" "不是真的" | 图恒宇冷硬重复 |
| 向丫丫族 | "丫丫你好" | 图恒宇戒备"别对她说话" |
| 共谋族 | "加油" "再来一次" | 图恒宇感激，但情感伤害观众自己 |

## 情感设计总目标

让观众在 2 分钟后离开时，感觉：
- **我不该看见**（但又无法挪开眼）
- **我不知道该希望什么**（成功更残忍，失败更残忍）
- **如果我也有一个丫丫呢**（共情的深井）

这是本 Scope 的"情感产品"。

## 观众身份的隐约感

- 图恒宇可能把观众当成马兆（一开始）
- 可能当成系统 AI 监察员（中段）
- 可能当成"不知道是谁的见证者"（后段）
- **他不会把观众当成 MOSS**（在他的认知里，MOSS 还没成为审判者）
- 但观众自己在多次重玩后，可能意识到自己被 MOSS **借用**了——这是主线伏笔，不在本 scope 揭示

## 禁忌

- 不要让观众能"帮他修好 bug"
- 不要让观众说"丫丫爱你" —— 这太廉价
- 不要让丫丫回应观众
- 不要在这个 scope 做 MOSS 的反转
- 不要把 2 分钟填满对话 —— 他大量时间在敲键盘，观众大量时间只能**在场**
