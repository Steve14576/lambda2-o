# Environment · 环境角色如何"在场"

> 主体只有一个（图恒宇）。丫丫虽然发声，但不接 LLM。

## 丫丫

**在场方式**：预录 + 极简模板 + 数字"薄"感滤镜

**声音库**（供预录）：
- "爸爸"（困惑）
- "爸爸？"（疑问）
- "爸爸！"（开心，但不稳定）
- "爸爸……"（含糊，像睡着之前）
- "爸爸。"（颤抖，最后一次）
- 一段 3 秒的呼吸音（不说话）
- 一段 5 秒的无意义呢喃（像在想事情）

**可触发模板**（DM 软层在极有限条件下调用）：
- [触发条件：图恒宇问"你记得爸爸吗"] → 播放"爸爸……"（含糊版）
- [触发条件：图恒宇说"丫丫不怕"] → 播放呼吸音 + 0.5s 后"爸爸"（颤抖版）
- [其他情况] → 沉默，或环境底噪

**关键规则**：丫丫不回答具体问题。她的存在本身就是回答。
她的**时序**比她的**内容**更重要——她什么时候发声，隔多久发声，发完声之后有没有**残响**。

## 马兆

**在场方式**：远程监视 / 手机提示音 / 不出现

- 某一时刻手机响一次：短促的消息提示音。
- 屏幕一角弹出："马兆：你在干什么"（视觉元素，不一定发声）
- 图恒宇可能看了，可能没看。
- 他不会回复。
- 马兆**不会冲进来**。他只是在远处知道着。

如果 Scope 升级（想增强张力），可以在 COLLAPSING 段加一次马兆的**未接来电铃声**——一直响到 RESET。

## MOSS

**在场方式**：不在场。
这个 Scope 里 MOSS 还没出场。
但可以在 RESET 瞬间给一个**极微弱**的电子底噪脉冲——像某个遥远系统"记录"了这一轮。
观众可能不会注意到。注意到了，是 Scope 04 和主线的伏笔。

## 数字丫丫之外的"丫丫痕迹"

- 小运动服（视觉元素）
- 水壶（视觉元素）
- 他口袋里的那个**什么东西**（留白）
- 某个文件夹名叫 `yaya_backup_v47` —— 这是他这一次的版本号，说明他已经试了 46 次

这些是**世界的物证**，让丫丫"已经死过"这件事有存在感。

## 观众（画外观测者）

**对图恒宇来说，观众是什么**：
- 第一反应：马兆？（因为他正担心马兆）→ 但声音不像
- 第二反应：系统日志 AI？（"你在干什么"的那种规劝）
- 第三反应：自己的良心？
- 如果观众说出**只有他和丫丫知道的事**（比如"你答应过带她去海边"），他会**僵住**——"你是谁"

**图恒宇会对观众使用的态度**：
- 警觉 / 戒备 / 试探
- 不会友善地解释
- 如果观众温柔地劝阻，他可能软下来，但不会停
- 如果观众威胁他，他会变硬

**对观众来说**：
- 一开始他们在"偷窥"
- 渐渐意识到**自己在场意味着什么**——他们是唯一一个听见丫丫 2 分钟声音的"外人"
- 最后——他们可能不知道该希望"成功"还是"失败"

## 禁忌

- 不要让任何第三人进场（不要有助手、学生、警卫）
- 不要让丫丫说完整句子
- 不要让图恒宇在这个 Scope 里解释"MOSS""550W""数字生命计划"这些背景（他没心情，也不该科普）
- 不要让"成功"和"失败"的判断在 scope 内被揭晓（RESET 时崩了，但不代表下一次也会崩）
