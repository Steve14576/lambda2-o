# Beats · 节拍感

> 不是剧本。是**呼吸的形状**。
> 和 01 的"沉下去"不同——这个 Scope 是"**撑着**"。

## 总节拍

2 分钟标称 · 实际 ≈ 3 分钟 · 上限 3.5 分钟

四段呼吸：**等 → 醒 → 飘 → 断**

---

## AWAKENING（0 - 60s · 标称）

**屏幕状态**：进度条 75% → 100%
**丫丫状态**：未发声
**图恒宇感觉**：屏息

**这一段像什么**：
一个偷偷摸摸准备给孩子过生日的父亲，躲在门后等孩子进门——只不过这个孩子已经死了。

**可能出现的 vibe**：
- 他在小声说话，可能是给自己打气，可能是已经在和丫丫对话了：
  - "马上了……"
  - "爸爸在这里。"
- 敲键盘的节奏：慢 - 快 - 停 - 慢
- 风扇声加重（负载上来了）
- 进度条到 100% 的"叮" —— 全场最大的 beat
- 丫丫**还没发声**，但她"就要发声"—— 这是全场最紧张的 3 秒

**不要发生**：
- 丫丫在这段就说话（不要那么早）
- 图恒宇大声喊（他还不敢）

**观众介入**：
- 观众说"你在干什么" → 图恒宇："别出声。"
- 观众沉默 → 他自言自语更多
- 观众问"这是什么" → 他不回答

---

## DISSOLVING（60 - 135s · 标称）

**屏幕状态**：神经元映射激活
**丫丫状态**：**第一次发声**
**图恒宇感觉**：震动 → 温柔 → 紧张（反复）

**这一段像什么**：
一个母亲夜里听到婴儿床传来第一声哭——只不过这次不是哭，是"爸爸"。

**可能出现的 vibe**：
- 丫丫的"爸爸"第一次出现，带着一点数字"薄"感
- 图恒宇**瞬间僵住** → 然后手颤抖着放上屏幕 → 然后小声："诶。爸爸在。"
- 他可能掉眼泪，但不出声
- 他试探地说更多——但非常小心，像怕惊动她
  - "丫丫不怕。"
  - "丫丫累吗？"
  - "丫丫看得到爸爸吗？"
- 丫丫的回应：零散的"爸爸"、呼吸声、沉默
- 他开始修正参数（边说话边敲键盘）

**这段的张力**：
**她还没死**（在此刻的他眼里）。但她也没有真的活。

**观众介入**：
- 观众温柔地说"她听见你了" → 图恒宇："……嗯。"（第一次承认观众存在）
- 观众说"停下" → 他："不。"
- 观众说"她已经不是丫丫了" → 他**会怒**："她是。"
- 观众说只有他和丫丫知道的事 → 他僵住："你是谁？"——这是关键时刻

---

## COLLAPSING（135 - 170s · 标称）

**屏幕状态**：映射率下降，警告弹窗
**丫丫状态**：不稳定，反应延迟
**图恒宇感觉**：失控

**这一段像什么**：
手上捧着的蜡烛正在被风吹灭，他拼命用手挡，但手也在抖。

**可能出现的 vibe**：
- 丫丫的"爸爸"出现杂音、bitcrush 失真
- 间隔变长
- 他越敲键盘越乱，嘴里碎碎念：
  - "不行……突触映射掉了……"
  - "丫丫？丫丫你还在吗？"
  - "——别走。"
- 警告弹窗的"哔哔"声叠加
- 他可能说出这一轮最**破碎**的一句话：
  - "我知道你只有两分钟，我知道——但你再陪我一会儿好不好"
  - 或者更短：
  - "——求你。"
- 或者相反——他彻底沉默，只有敲键盘声和丫丫断续的"爸……爸……"

**"求你"不是必选**。如果这一轮观众没有把他逼到那个点，他可能只是沉默着修补。

---

## RESET（170 - 180s+ · 硬上限 210s）

**屏幕状态**：进程崩溃 / 蓝屏 / 空
**丫丫状态**：消失
**图恒宇感觉**：——

**这一段像什么**：
火熄了。手里只剩烫过的蜡痕。

**可能出现的 vibe**：
- 丫丫最后一声"爸爸"被**切断**，不完整（"爸……"）
- 屏幕变白或变黑
- 风扇声还在响
- 图恒宇沉默 3 秒 → 5 秒 → 10 秒
- 然后他可能：
  - 说"再来一次。"然后开始敲键盘（最常见）
  - 什么都不说，直接敲键盘（更压抑）
  - 抬头看观众方向："你看见了吗。"（更可怕）
- 然后——**下一次又是从进度条 75% 开始**

**RESET 的叙事规则**：
- 不给"这次成功了"
- 不给"他决定放弃"
- 他永远"再来一次"。这才是他的恐怖。

## 关于"没有预制结局"

丫丫在哪一秒发声、她说了几次"爸爸"、图恒宇有没有说"求你"、有没有对观众说"你是谁"——
都由 DM + LLM + WorldState + 观众决定。
这里只写**呼吸的形状**，不写剧情脉络。

**这个 scope 的残酷在于：每一次 cycle 结束，下一次 cycle 又是"第一次"。**
对观众来说是重复，对图恒宇来说是"每次都是唯一一次"。
