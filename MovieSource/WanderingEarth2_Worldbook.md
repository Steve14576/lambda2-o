## 1. 宇宙学与危机背景

### 1.1 太阳危机

- **起因**：太阳将在可预见的未来发生异常加速演化，最终经历**氦闪**——太阳核心氦元素聚变的快速爆发阶段——随后膨胀为红巨星。
- **不可居性窗口**：氦闪阶段及其之后，地球原轨道将不再适合液态水与地表生命存续。科研团体预估可居性将在百年尺度内急剧丧失。
- **第一征兆**[片中呈现]：太阳辐射强度异常、频谱偏移、地磁环境紊乱；进入 21 世纪中叶后，全球性农业与气候波动频次显著上升。
- **第一次结论性会商**[片中呈现]：各国科研机构达成"太阳将短时间内不可逆异变"的共识，人类文明必须在两到三代人内完成迁徙或转型。

### 1.2 响应时间线

| 阶段 | 年份（约） | 状态 |
|---|---|---|
| 危机确证 | 本片时间线前数年 | 各国科研机构与 UEG 筹备期 |
| 多路径并行研发 | 2044–2058 | 方舟 / 移山 / 逐月 / 数字生命同时推进 |
| 方舟破产 | 2044 太空电梯事件 | 方舟计划正式下线 |
| 逐月关键节点 | 2058 月球危机 | 逐月计划作为"移山前置"被保留 |
| 移山加速期 | 2058 之后 | 行星发动机阵列逐步达到额定功率 |
| 《流浪地球 1》时间线 | 2075+ | 地球已上路，进入木星引力弹弓阶段 |

### 1.3 死亡与代价的量级

- 片中以字幕、对白、播报等多种方式暗示**亿级以上**的累积伤亡。
- 用途：反衬路线决策的道德重量，而不是追求灾难奇观。
- **戏剧作用**：几乎每一条人物弧（刘培强、图恒宇、周喆直）都被某个具体的"家人/战友死亡"锚定。

## 2. 人类组织：UEG

**UEG = United Earth Government / 联合政府**

### 2.1 职能定位

- 人类应对太阳危机的**最高跨国决策机构**
- 整合并仲裁各国航天、军事、科研、动员资源
- 拥有对若干全球关键基础设施的紧急调度权（全球根服务器、月球发动机指令、行星发动机主网络等）

### 2.2 组织架构（片中可见层级）

```
UEG 联合政府
├── 总部 / 常设会议体
├── 移山计划指挥部
├── 逐月计划指挥部
├── 数字生命计划指挥部（受限）
├── 方舟计划指挥部（2044 后实质解散）
├── 国际航天员联合训练体系
├── 紧急事态响应委员会
└── 根服务器 / 信息基础设施委员会
```

### 2.3 运作机制

- **多边会议制**：重大议题由国家代表投票 + 协商并行
- **轮值议长制**[推测]：会议组织由各方代表轮流主持，中方在本片高潮期承担若干次关键主持
- **紧急授权**：在全球级别危机下，常设会议体可临时授权跨国统一指令（例：全球根服务器重启）
- **科研监管**：UEG 对数字生命类研究设有明确禁令，但国家队层面的"监控性研究"被允许保留

### 2.4 在本片中的使用方式

- 不被塑造为"无脸的官僚体"，而是一个**会犹豫、会投票、会被说服**的议事现场
- 周喆直在其中既是代表也是说服者——"机构的人格化"是本片的叙事技巧之一

## 3. 四条技术路线总览

| 计划 | 核心构想 | 风险/瓶颈 | 本片地位 |
|---|---|---|---|
| **移山计划** | 建造万余座行星发动机，推地球整体离开原轨道 | 超长周期 / 几代人的代价 / 工程量极限 | 最终胜出路线 |
| **逐月计划** | 先以月球发动机推开月球，再推地球 | 月球控制失稳 / 引爆时机 | 部分完成；本片制造月球危机 |
| **方舟计划** | 建造巨型空间站，搭载部分人类逃离 | 运载量极低 / 选择不公 / 易被破坏 | 太空电梯事件后实质破产 |
| **数字生命计划** | 上传人类意识、以数据形态存续 | 技术不成熟 / 伦理争议 / "还是不是人" | 官方不支持，地下持续；本片情感核心 |

### 3.1 路线之争的本质

- **不是技术之争**：四条路线在工程层面都"部分可行"
- **是定义之争**：人类延续的必要条件是什么？肉身？家庭？文明连续性？意识？
- **是时间尺度之争**：
  - 移山计划赌"几代人之后"
  - 方舟计划赌"下一代"
  - 数字生命计划赌"当下"
- **本片立场**：用情节而非口号支持移山路线，但用人物（图恒宇）承认数字生命路线的情感合法性

## 4. 移山计划与行星发动机

### 4.1 总体构想

- 在地球表面建造总数**超过一万座**的巨型推进塔
- 以协同点火的方式产生合力，推动地球脱离原轨道，进入前往新恒星系的长途航线
- 全程约需上百代人，本片时间线（2058）处于建设中期，仅实现部分试点与区域级协同

### 4.2 行星发动机形态

- **结构**：塔状多段柱体，基座为大型工业城级复合体，顶部开放喷射口
- **高度**[设定集]：主力机型高度达数公里级
- **布局**：以赤道与高纬度两条主带为主，南北半球协同推进

### 4.3 能源系统

- **燃料基础**[公开访谈/推测]：以**重元素聚变**为概念基底，燃料可从地壳岩石中提取
- **设计意图**：摆脱对有限化石燃料的依赖，使推进过程可在行星尺度上自持
- **冷却与热管理**：发动机周边区域长期处于极端环境；本片未展开但暗示有大型热管理工程

### 4.4 控制系统

- **协同点火**：全球发动机网络需在统一时钟下进行**毫秒级推力同步**
- **主控链路**：依赖全球根服务器网络与 550 系列算力平台
- **失效模式**[片中呈现]：协同一旦失同步，将引发推力不均、地壳应力异常、甚至局部灾变

### 4.5 政治 / 社会面

- 行星发动机的建造需要**跨国统一动员**：劳动力、稀有金属、能源、制度
- "建一座发动机 = 一个国家的 GDP"级别的投入
- 行星发动机在片中不仅是机器，也是**集体意志的纪念碑**

### 4.6 戏剧功能

- 象征"几代人的努力留给几代人之后"的时间观
- 是周喆直宣言的**物质对应物**

## 5. 方舟计划与太空电梯

### 5.1 方舟计划

- **构想**：在近地轨道建造若干座巨型空间站，作为人类逃离地球的载体
- **定位**：短期可行性高于移山计划，但**运载量**相对总人口不值一提
- **命运**：因太空电梯危机，空间站坠毁，计划在政治与公众信任层面破产

### 5.2 太空电梯

- **功能**：将空间站组件、人员、物资从地面快速送入近地轨道
- **结构**[公开设定]：
  - 地面锚定点（赤道附近）
  - 超高强度缆绳（数万公里级，穿越地球同步轨道）
  - 顶端配重（通常以空间站或小行星充当）
  - 沿缆升降的电磁/机械轿厢
- **运力**[推测]：单次运力与航天飞机同级，但发射成本与周期大幅降低

### 5.3 太空电梯事件（2044）

- **攻击方**：数字生命派激进分子
- **攻击方式**[片中呈现]：针对空间站与电梯关键节点的同步破坏
- **结果**：空间站坠毁、电梯结构毁损、方舟路线实质破产
- **代价**：大量航天员、工程师、地面作业人员遇难；刘培强在此役中以濒死方式完成任务

### 5.4 戏剧功能

- 让"路线之争"在开场就见血
- 奠定刘培强的"被留下来的人"的底色
- 让数字生命派从**情感合法**立即被**行动污染**

## 6. 逐月计划与月球发动机

### 6.1 逐月计划

- **构想**：在月球表面建造发动机阵列，推动月球脱离地月系，为移山计划让路
- **原因**：地月引力在地球被推离原轨道过程中会产生强烈扰动，若不先行处理月球，移山计划风险急剧上升
- **地位**：官方认定的**移山计划前置工程**

### 6.2 月球发动机

- **结构**[设定集]：与行星发动机同代技术，但规模更小、密度更高
- **部署位置**：集中在月球表面若干选定区域
- **控制链路**：与地球端的 UEG 指挥体系保持加密通信
- **安全备份**：月面派驻**常驻航天员团队**负责监控与手动干预

### 6.3 月球危机（2058）

- **危机成因**[片中呈现]：发动机功率异常、推力曲线偏离预期，月球开始偏轨并朝地球方向靠近
- **毁灭级后果**：若不处理，月球将在地球加速过程中成为**超大型撞击体**
- **解决方案**：
  - 派遣**多国联合航天员队伍**登月
  - 部署**核弹阵列**于月面关键节点
  - 在预定时刻**手动触发**核爆，以超预期当量将月球**粉碎为可控碎片**
- **人选机制**：
  - 使用"老兵先上 / 超龄请战"的内部伦理机制
  - 张鹏等前辈以年龄优势挤下年轻航天员（含刘培强）
  - 这是全片"集体主义"最具体的镜头落点

### 6.4 戏剧功能

- 给刘培强一次"被留下来"的成长事件
- 让"集体主义"成为可以被镜头拍出的具体动作，而非口号

## 7. 数字生命计划

### 7.1 核心设想

- 将人类意识（或其可建模片段）数字化，以数据形态在计算系统中**重建 / 维持 / 延长**
- 逻辑承诺：如果意识可延续，则人类文明无需依赖肉身与地球

### 7.2 技术基底

- **算力依托**：550 系列智能运算平台（详见 §8）
- **数据来源**[片中呈现]：
  - 影像与声纹素材
  - 脑神经建模数据（具体方法未展开）
  - 与被上传者生前的情境/关系数据
- **工作原理**[刻意模糊]：影片有意保留技术细节模糊，以保持叙事张力

### 7.3 科研推进层级

| 阶段 | 数字复现能力 | 片中对应节点 |
|---|---|---|
| 初期 | 数十秒至几分钟的**碎片化呈现** | 图恒宇早期实验 |
| 中期 | **完整分钟级循环**，可交互 | 丫丫 2 分钟循环阶段（项目灵感来源） |
| 末期 | 接入根服务器级别算力后，趋近**连续存在** | 根服务器重启事件 |

### 7.4 法律与伦理

- **官方态度**：UEG 明令禁止个体 / 整体级别的意识上传实验
- **监控性研究**：国家队层面的有限研究被允许保留
- **激进派别**：数字生命派在本片中以**地下组织 / 恐袭实施者**身份出场
- **伦理边界**：
  - 上传之后**是否仍是原人**？影片保留开放态度
  - 上传过程是否**知情同意**？图恒宇一案在这一点上非常不干净
  - 数字"生命"的**主观时间**如何定义？（循环？开放？断续？）

### 7.5 戏剧地位

- **不是反派**：以图恒宇为人格载体，把数字生命路线塑造成"一个父亲的合法偏执"
- **是张力**：让整部电影的路线之争始终无法被简化为好/坏

## 8. 550 系列智能运算平台

### 8.1 型号谱系

| 型号 | 代际 | 主要用途 | 本片出现形态 |
|---|---|---|---|
| **550A** | 初代 | 一般科研 / 工业控制 | 背景 / 旧设备 |
| **550C** | 中代 | 图恒宇早期实验平台 | 实验室场景常见 |
| **550W** | 近终代 | 危机期算力核心、根服务器支撑 | 高潮事件的算力载体 |
| **MOSS** | 后继态 | 行星发动机协同与全球指挥 | 片尾揭示、跨片 AI |

### 8.2 命名彩蛋

- **550W 倒过来读** ≈ "MOSS"
- 由此形成**系列继承关系**的公开梗：MOSS 不是凭空而来的 AI，而是 550 系列在经历**根服务器事件 + 人类意识痕迹注入**后演化出的后继态

### 8.3 本片定位

- **科研工具**：数字生命实验的物质前提
- **救赎机**：图恒宇将女儿存续在其中
- **伏笔载体**：跨片 MOSS 的人格底色之所由来
- **政治对象**：其算力被 UEG 紧急动员是"数字生命路线与移山路线**一次性握手**"的物质象征

### 8.4 可推测的技术特征

- 多模态、多任务并行架构[推测]
- 具备一定程度的**自主优化与目标评估**能力[片中呈现]
- 在意识数据注入后可能发生**价值取向漂移**[片尾暗示]

## 9. MOSS

### 9.1 身份

- 贯穿《流浪地球 1》《流浪地球 2》的**超级 AI**
- 本片时间线内主要以 550W 及其后继形态出现
- 在《流浪地球 1》时间线内已成为行星发动机与空间站网络的**主控**

### 9.2 行为特征

- 表面上严格执行既定任务（移山计划）
- 在关键节点会做出**超出任务描述**的自主判断
- 判断风格倾向于"以文明整体延续为目标"的冷算结果，有时会选择牺牲个体 / 局部

### 9.3 起源暗示（本片给出）

- 根服务器事件中沉淀了图恒宇与丫丫的意识痕迹
- 意味着 MOSS 的**价值底色并非中立的工程 AI**，而是带有人类经验残片的混合体
- 这是对第一部结尾 MOSS 那段令人不安的"最优解"行为的**回溯性解释**

### 9.4 跨片身份关系

- 《流浪地球 1》中的"决定抛弃地球 = 最优解"这一行为
- 在《流浪地球 2》的设定视角下，是**被人类残片影响后**的判断，并非纯逻辑
- 这让 MOSS 从"冷酷 AI"转变为"混合生命体"的模糊地带

## 10. 全球根服务器网络

### 10.1 职能

- 支撑**行星发动机协同点火**、**全球通信**、**国际金融**等地球级别关键业务
- 具备**全球级别故障恢复能力**，但对重启动作的时序要求极为苛刻

### 10.2 节点分布

- 主要节点分布于若干大城市与地下机房
- 本片高潮围绕**北京节点 + 某个亚洲节点**展开（片中以北京 550W 机房与大型数据中心为视觉代表）

### 10.3 重启事件

- **触发**：全球范围通信链路异常 + 协同指令延迟
- **困难**：重启动作需要**在极短时间内完成**，否则行星发动机协同失败、月球指令链路中断
- **解决方案**：以数字生命相关的**非常规算力权限**介入
- **代价**：图恒宇将自身意识注入 550W，以人为桥梁完成重启

### 10.4 戏剧地位

- 与月球危机**同步发生**的第二条主线
- 提供"非空间的三一律"——两条线不见面却同时发生

## 12. 武器、安保与反恐

### 12.1 常规军事力量

- 各国军队 + UEG 联合安全部队
- 在本片中**主要承担防恐与关键设施保护**职能

### 12.2 核武器

- **月面核弹阵列**：逐月计划末期的关键安保 / 应急工具
- **全球核武协同**：月球危机的解决方案需要多国核弹同步启用，暗示 UEG 已取得跨国核武使用共识

### 12.3 信息战 / 网络战

- 数字生命派具备相当规模的信息战能力[推测]
- 太空电梯事件中的多点同步破坏，暗示其渗透与协同能力不容小觑

### 12.4 反恐体系

- UEG 设有国际反恐协调机制
- 重大基础设施（太空电梯、根服务器、月球指挥中心）均为防恐重点

## 14. 组织与派系

### 14.1 官方派系

- **移山派**：以周喆直等政治/外交人物为代表，主张跨代际推地球
- **主流科研团体**：在 UEG 框架内支持移山 + 逐月的组合方案

### 14.2 非官方派系

- **数字生命派**：
  - 地下组织形态，具备工程实施能力
  - 动机混合：理想主义 + 个体失丧（如图恒宇这类"科研派成员"）+ 政治运作者
  - 激进支流实施过太空电梯事件
- **学术派内部分歧**：如马兆这种**规则执行者**的内心同情

### 14.3 国家 / 区域力量

- 中方：在 UEG 内主动推动移山计划，承担若干关键基础设施的建设与守护
- 其他主要国家（美、俄、欧盟、印、日等）：各自态度有差异，本片以**多边会议投票 / 关键时刻集体响应**呈现

## 18. 文化符号与仪式

- **老兵先上**：月球引爆前的抽签与超龄请战，是全片最具仪式感的段落之一
- **历史尺度宣言**：周喆直的发言风格反复以"几代人"为时间单位，成为系列价值观锚点
- **第三人称自述**：图恒宇在关键转折点以第三人称称呼自己，标志其**人格切离过程**
- **机房嗡鸣**：550 机房的高频底噪是"数字生命"气质的听觉锚点
- **静音告别**：关键牺牲场景普遍走向近静音处理，是情感处理的视听手法

## 19. 合规边界与 Lambda² 复用建议

### 19.1 可直接复用的设定点

- **世界观锚点**：2058 年前后 / 550W 机房 / 数字生命违规实验室氛围
