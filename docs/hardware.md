# Lambda² · 硬件采购详单

> 本文档是 [DEVELOPMENT.md §8](./DEVELOPMENT.md#8-硬件采购清单) 的详细版。
> 展位日一切硬件以本文档为准。

---

## 采购原则

1. **本周必须全部下单**,否则来不及到货调试
2. **总预算上限 300 元**(不含备网 SIM 卡套餐)
3. **有线 > 无线,标准 USB > 特殊接口,可冗余 > 单点**
4. **不买**:蓝牙耳机、一分二音频分配器、老式座机(已放弃)、USB 拓展坞(用不到)

## 1. 核心设备:USB 有线带麦头戴耳机

### 1.1 首选型号

**罗技 H390** —— ¥130 左右

| 维度 | 评价 |
|---|---|
| 接口 | USB-A(系统即插即用,无需驱动) |
| 麦克风 | 电容式、可弯折定位 |
| 麦克风降噪 | 内置,展位嘈杂环境够用 |
| 舒适度 | 皮质耳罩,轮流戴 30 分钟内可接受 |
| 线材 | 1.8 米,配合延长线够用 |
| 音质 | 40mm 单元,人声清晰(不求 HiFi) |
| 稳定性 | 企业客服标配,稳定性经长期验证 |

### 1.2 备选清单

| 型号 | 价格 | 优点 | 缺点 |
|---|---|---|---|
| 漫步者 K815 | ¥80 | 便宜 | 做工一般,佩戴久压头 |
| 西伯利亚 K9 | ¥100 | 低频重,MOSS 电流感有加成 | 外形偏游戏风,与"座机替代"气质不符 |
| 雷蛇 Kraken X USB | ¥220 | 隔音最好 | 超预算,压头感强 |
| 网易 UU 耳机 | ¥100 | 麦克风清晰 | 型号迭代快,可能断货 |

### 1.3 选型依据
- **为什么必须 USB 不用 3.5mm**:USB 耳机系统识别为**独立音频设备**,Python `sounddevice` 可按设备名/ID 精确绑定,排除笔记本内置麦克风误采;3.5mm 走板载声卡,输入输出共用设备,不好隔离
- **为什么必须带麦不买分离麦**:展位空间有限,少一根线少一次失败点
- **为什么不上游戏耳机**:外观与"数字生命意识切片"装置氛围违和

### 1.4 采购数量
- **1 条主用 + 1 条备用**(备用不拆封,现场坏一即换)
- 总计 2 条,¥260

## 2. USB 延长线

### 2.1 规格要求
- USB-A 公 → USB-A 母
- **3-5 米**(桌面走线 + 观众就位距离 2 米有余)
- **带信号增强芯片**(超过 3 米的被动延长线可能掉帧,尤其是 USB 音频这种等时传输)
- USB 2.0 够用(音频带宽远低于 USB 2.0 上限)

### 2.2 推荐品牌
- 绿联、山泽、优越者(¥15-25)
- **带磁环**的更抗干扰,展位附近有荧光灯/电源适配器时建议

### 2.3 数量
- 1 根主用 + 1 根备用 = 2 根,¥40

## 5. 网络备份:4G/5G 随身 WiFi

### 5.1 必要性
- 展位公网依赖:LLM SaaS + 学长服务器 TTS,**两条公网链路**
- 校园嘉年华人多 → AP 拥堵 → 大概率丢包
- **这是保底设备,不是可选**

### 5.2 选型方案

**方案 A:借手机热点(零成本)**
- 用自己手机开热点
- 风险:电池、来电、微信通知、手机挂起
- 可以做临时应急,不做主力

**方案 B:随身 WiFi 设备**
- 华为 / 中兴 / 格行随身 WiFi 设备,¥80-150
- 配套月卡 ¥30-80/月
- **运营商选择**:展位前实地测 3 家信号(电信/移动/联通)
- 嘉年华场地一般电信 4G/5G 较稳

**方案 C:双卡备份**
- 主力随身 WiFi + 手机热点备份
- 展位日其中一个切换另一个无缝

### 5.3 推荐
- 随身 WiFi 设备 ¥80 + 展位当月大流量卡 ¥30
- 展位前 1 周到货,现场实测延迟

## 6. 可选:方向性麦克风改造(Phase 7 考虑)

### 6.1 问题场景
- 展位相邻摊位喧哗 → 头戴麦克风误采 → VAD 误触发
- 观众以为自己没说话 → 系统突然打断 → 体验破坏

### 6.2 解决方案
- **提高 VAD 阈值**(代码优先,免费)
- **物理方案**:USB 心型指向桌面麦 + 关掉头戴麦
  - 但要多一个设备 + 多一次 sounddevice 路由配置
- **简单方案**:头戴麦克风端套海绵防风罩(¥5),虽然主要防风但也能吃掉一些侧向声

### 6.3 建议
- Phase 4 硬件联调后实测,**如果 VAD 误触发率 <5% 就不买**
- 超过 5% 再考虑加装

## 7. 展位布置建议

### 7.1 桌面布局(从观众视角)

```
┌──────────────── 桌面 (1.2m × 0.6m) ────────────────┐
│                                                     │
│  [展位立牌]                         [笔记本(偏里侧)] │
│   Lambda²                                           │
│   "戴上,听"                                          │
│                                                     │
│                                                     │
│                                                     │
│  [耳机挂架]─── USB 延长线走桌面边缘理线夹 ───────────┘
│   ↓
│  [一次性耳套盒] [湿巾盒] [垃圾袋(挂桌下)]
│
│  观众站位
```

### 7.2 关键布置原则
- 笔记本**屏幕朝自己(运营者)**,观众看不到屏幕(黑屏设定 + 避免 debug 信息穿帮)
- 耳机线走**桌面外侧边缘**,不跨桌面
- 耳机**挂在挂架上**(低成本 3D 打印或带钩支架,¥15),不放桌面避免倒
- 垃圾袋挂桌下,用后耳套随手扔

### 7.3 电源
- 展位一般有 1 个 220V 插座
- 需要:**笔记本电源适配器** + **随身 WiFi 充电线** + **(可选)USB 集线器给耳机供电**
- 带一个 **4-5 口排插**(¥30),留 1-2 个冗余口
- **UPS 不必**(展位停电就收场,不是数据中心)

### 7.4 照明
- 展位灯光**不影响技术**,但影响装置氛围
- 建议暗调:桌面只留一盏暖色小台灯(¥30-50)照亮耳机
- 装置感 +++、黑屏气质不被破坏

## 9. 到货验收 Checklist

每件到货按顺序核对:

### 9.1 耳机
- [ ] 外观完好、线无破损、接口干净
- [ ] 插入笔记本 USB,Windows 设备管理器识别为 `Logitech USB Headset H390`
- [ ] 在 `设置 → 声音` 看到为输入/输出设备
- [ ] 用任意录音软件试录 10 秒,回放清晰
- [ ] `uv run python scripts/check_env.py` 能找到设备并报告采样率

### 9.2 USB 延长线
- [ ] 耳机接到延长线末端后仍被识别
- [ ] 录音无杂音、无掉帧
- [ ] 线身无异味(劣质 PVC 会有)

### 9.3 随身 WiFi
- [ ] 校园嘉年华场地**实测**延迟 + 丢包(不是宿舍测)
- [ ] `ping 8.8.8.8` 和 `ping tts.mentor-server.local` 分别 <80ms / <150ms
- [ ] 模拟 WS 连学长 TTS 服务,跑 5 分钟无断连

### 9.4 全套联调
- [ ] 耳机 + 延长线 + 随身 WiFi + 笔记本 同时工作
- [ ] 跑 `scripts/latency_bench.py`,端到端首音 <2.5s
- [ ] 跑 10 轮 2 分钟回路,无崩溃

## 11. 不买清单(明确避坑)

| 品 | 原因 |
|---|---|
| 蓝牙耳机(AirPods 等) | 延迟 + 抢连 + 2.4GHz 拥堵 |
| 3.5mm 一分二分配器 | "两人共听一场"破设定 |
| 老式座机 | 已放弃,改装成本 + 音质差 |
| USB 拓展坞 | 展位只用一个 USB 端口,不需要 |
| 专业监听耳机 | 价格翻倍,展位场景过剩 |
| 降噪耳机(主动降噪) | 观众听不到环境反而不安全(比如有人叫他) |
| 高端电容麦 | 头戴麦够用,多一根线多一个锅 |
| 声卡(USB 外置) | 没必要,USB 耳机自带数字音频 |
| LED 氛围灯带 | 破黑屏气质 |
