## 1. 项目性质界定

### 1.1 性质
- **同人二次创作**(derivative fan work)
- **非商用**:不销售、不接广告、不收费、不带货、不对外引流
- **非盈利**:作者不从本项目获得任何金钱、代币、广告分成
- **学习/展演性质**:校园嘉年华 + GitHub 学习目的开源

### 1.2 目标作品
- 改编自电影《流浪地球 2》(中国电影股份有限公司出品,2023)
- 涉及角色:图恒宇、马兆、MOSS、图丫丫
- **不使用**电影原声、原画、原曲、海报

### 1.3 声明
本项目是**粉丝创作**,与:
- 原电影制作方无关联
- 原著作者刘慈欣无合作关系
- 主演、配音演员(刘德华、宁理、刘琮等)无商业合作

## 2. 线下展演版合规

### 2.1 允许
- 在校园内一对一展演
- 可以包含图丫丫角色(保守处理,见 §4)
- 可以使用模仿电影角色音色的 AI 语音(TTS 参考音来自公开片段)
- 可以分享给同学、社团、展览活动

### 2.2 禁止
- ❌ 展位不录屏
- ❌ 不上传任何体验录音到公开平台(B站/抖音/微博/小红书)
- ❌ 不印售周边
- ❌ 不宣传"官方"、"合作"、"授权"
- ❌ 不展示演员真实姓名、肖像、签名

### 2.3 展位立牌文案(强制)

**正面(观众视角,靠前)**:
```

数字生命意识切片

戴上耳机, 听见两分钟的轮回
```

**背面(作者视角,靠桌面)**:
```
同人非商用展演 · 非官方作品
改编自《流浪地球 2》 · 与原制作方无关
AI 合成语音, 非演员本人录音
```

**小贴纸(贴在耳机架旁)**:
```
体验仅限展位, 内容不录制、不上传
```

### 2.4 展位日免责提示(可选但推荐)

贴一张 A4 纸说明,观众等候时可读:

## 4. 未成年人 AI 合成边界(最敏感项)

### 4.1 红线

**必须做到**:
- 开源版**完全**不包含图丫丫
- 线下版图丫丫的所有音频**不分发、不上传、不保留**(展后擦除)
- 图丫丫 prompt 禁止产生任何:痛苦、求救、死亡、畸变、恐怖相关文本
- 不使用任何**真实**未成年人的声音作为 TTS 参考音

### 4.2 为什么这么严
- 未成年人 AI 合成音在国内外都是高敏感话题
- 即便是"剧中未成年角色"的 AI 仿声也有争议
- 保守策略:线下内部使用 + 严格童真语气 = 不触红线;开源 = 完全删除

### 4.3 实施检查
- [ ] `docs/characters.md` §6 图丫丫 prompt 禁止清单完整
- [ ] `tests/test_compliance.py` 包含图丫丫 output 禁词回归测试
- [ ] 展位日笔记本有一个 `cleanup.sh`,收场后自动删除所有录制的临时文件

## 6. 电影原作素材边界

### 6.1 明确禁止
- ❌ 电影原声(整段 BGM、插曲)
- ❌ 官方海报、角色剧照、官方 logo
- ❌ 片花、预告片 clips
- ❌ 官方周边设计
- ❌ 官方脚本文字

### 6.2 允许
- ✅ 对故事背景的**文字描述**(视为二次创作原料)
- ✅ 角色名字
- ✅ 550W、MOSS、数字生命等世界观设定
- ✅ 基于原世界观进行的**原创**剧情(本项目 2 分钟切片就是原创)

### 6.3 灰区处理
| 素材 | 判断 | 处理 |
|---|---|---|
| 电影名台词(如"飞船的本质是棺材") | 灰 | 避免整句照搬,可化用 |
| 干声参考(TTS 输入) | 灰 | 仅运行时用,不分发 |
| 环境音灵感(机房嗡鸣) | 安全 | 自行录制或免版权库下载 |
| UI 设计(MOSS 红光) | 灰 | 本项目无画面,不涉及 |

## 7. 下架应对预案

### 7.1 触发条件
- 原制作方、演员经纪公司、出品方发来 Issue / 邮件 / 律师函
- GitHub 收到 DMCA takedown 通知
- 媒体报道引发舆论争议
- 校方要求停展

### 7.2 响应流程
1. **24 小时内**:
   - README 顶部加大字号致歉声明
   - 仓库切为 private(保留代码不丢)
   - 线下展演立即停止
2. **72 小时内**:
   - 回复对方说明:本项目性质、采取的合规措施、后续改动意向
   - 如对方要求完全删除 → 删除仓库、擦除所有相关资料
   - 如对方要求局部修改 → 协商后照改
3. **7 天内**:
   - 无论结果:publicly 更新社媒 / issue 回应说明处理结果

## 8. 隐私与数据

### 8.1 观众语音数据
- **原则**:不录制、不存储、不上传、不分析
- 实现:
  - ASR 结果仅保留在内存中
  - 每轮结束后 `WorldState.reset()` 清空 session history
  - 笔记本关机即全部数据消失
- **绝对禁止**:
  - 把观众语音发到云端 ASR API(会有厂商留存)
  - 把观众语音转文字后做数据集
  - 以任何形式公开观众的原话

### 8.2 系统日志
- `structlog` 输出只包含:
  - `run_id`、`cycle_id`
  - `stage` 切换事件
  - `latency` 测量
  - 异常堆栈
- **不记录**:
  - 观众语音内容
  - LLM 完整对话(调试期例外,展位日关闭)
- 日志文件**不上传**,本地保留 7 天后自动清理

### 8.3 LLM API 的 token 留存
- qwen / doubao 等 SaaS 厂商的 API **默认会在后端留存一段时间**用于模型改进和安全审计
- **不可控**,但观众语音已经本地 ASR 成文字,文字本身已脱敏(没有声纹)
- 为进一步保护:可以在文字发给 LLM 前做一轮**观众 ID 模糊化**(本项目不收集 ID,天然脱敏)

### 8.4 展位立牌再提示
展位立牌已在 §2.4 声明:"您的语音不会被录制、存储或上传"。
这一句必须真实做到,否则是**更大的合规问题**。
