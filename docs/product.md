# Lambda² · 产品需求文档 (PRD)

> 单人项目的 PRD **不填大厂模板**,只回答四个问题:
> **做什么 · 给谁 · 为什么 · 怎么算成功**。
>
> 本文档关心"是什么",不关心"怎么做"(那是 [DEVELOPMENT.md](./DEVELOPMENT.md) 的事)。

---

## 1. 一句话定位

> **Lambda²** 是一个 2 分钟一对一沉浸式黑屏语音装置,让观众以"话外观测者"身份介入一段《流浪地球 2》数字生命的意识轮回切片。

---

## 2. 给谁(目标受众)

### 2.1 线下展演版
- **主受众**:校园嘉年华路过的学生(对科幻/AI/流浪地球有初步好奇即可)
- **次受众**:社团成员、科创/电影爱好者社群、老师
- **不针对**:小孩(10 岁以下)、完全不了解科幻的纯路人(会 miss 掉全部梗)

### 2.2 GitHub 开源版
- **主受众**:想做"语音多 agent"、"流式对话"、"沉浸式装置"的开发者
- **参考价值**:
  - 纯语音 + LLM 多 session 的工程实践参考
  - CosyVoice 2 分布式部署实例
  - 硬件 + 软件 + 合规一体化的小项目模板

---

## 3. 做什么(核心体验)

### 3.1 单轮体验时序
```
观众到摊位 → 戴耳机 → 进入 2 分钟意识轮回 → 体验结束 → 反馈(可选)
```

### 3.2 2 分钟内发生什么

| 阶段 | 时长 | 观众感受 | 系统行为 |
|---|---|---|---|
| AWAKENING 平稳 | 0-40s | 柔和机房嗡鸣,角色醒来、简短对话 | 情绪基线 calm,侵蚀率 0-30% |
| DISSOLVING 侵蚀 | 40-90s | 底噪变浑,人声开始滤波,异样感出现 | 情绪基线 uneasy,侵蚀率 30-65% |
| COLLAPSING 崩坏 | 90-115s | 滤波厚重、爆音、角色崩溃或麻木 | 情绪基线 grief/numb,侵蚀率 65-95% |
| RESET 重置 | 115-120s | 全部声音渐弱至静默 3 秒 | 强制 reset,准备下一位 |

### 3.3 观众能做什么
- 开口说话 → 角色会(有一定概率)回应
- 打断 → 可以随时打断角色话语(barge-in)
- 沉默 → 也能完整走完 2 分钟,剧情自走

### 3.4 观众**不能**做什么
- 跳过阶段 / 延长时间 / 重开一轮
- 选择角色 / 切换场景
- 触发显式"剧情选项"(没有 A/B/C 按钮)
- 录音 / 截屏 / 分享

## 4. 功能范围

### 4.1 In Scope(必做)
- ✅ 流式双向语音交互(ASR → LLM → TTS + barge-in)
- ✅ 4 个独立 LLM 角色 session(DM + 图恒宇 + 马兆 + MOSS)
- ✅ 2 分钟 FSM 三阶段自动推进
- ✅ 音频特效(按 stage 动态滤波 + 环境底噪 + 崩坏音效)
- ✅ 远程 + 本地 + 预录三级 TTS 降级
- ✅ 硬件 checklist + 展位运行手册
- ✅ 合规声明 + 开源版自动阉割未成年角色

### 4.2 Stretch Goals(有时间才做)
- ⚪ 图丫丫角色闪现片段(仅线下)
- ⚪ "插 U 盘 / 陨石 / 修服务器淹水" 三个特殊场景 FSM 节点
- ⚪ 调试 Web UI(gradio)做展位监控面板
- ⚪ 多语言(英文版,GitHub 海外用户)

### 4.3 Out of Scope(明确不做)
- ❌ 画面 / 3D / UI(永远黑屏)
- ❌ 多人同时体验
- ❌ 蓝牙 / 无线音频
- ❌ 手机端 / Web 端
- ❌ 剧情自定义编辑器
- ❌ 观众账号 / 体验历史 / 排行榜
- ❌ 商业化(付费 / 广告 / 周边)
- ❌ 移植到 Unity / Unreal / VR

## 5. 成功指标

### 5.1 线下展演版

**硬指标**:
- 开展当天 ≥ 4 小时连续运行**不停摆**
- 端到端首音延迟 < 2.5s(p95)
- 打断响应延迟 < 300ms(p95)
- 单轮 2 分钟完整完成率 ≥ 90%(观众不中途离开)
- 故障导致的降级(切预录模式)总时长 < 30 分钟/天

**软指标**:
- ≥ 30% 观众体验结束后主动留下反馈
- 反馈中 "沉浸" / "压抑" / "有感觉" / "有意思" 等积极关键词 ≥ 50%
- **没有**观众投诉(身体不适 / 惊吓 / 内容不适)

### 5.2 GitHub 开源版

**硬指标**:
- Release 当天至少完成:README + LICENSE + DEVELOPMENT.md + Demo 视频
- `uv sync` 能在 Windows/macOS/Linux 一次跑通
- `just check` 能正常输出环境报告
- 合规自检脚本 `scripts/compliance_check.py` 通过

**软指标**:
- 半年内 ≥ 10 star(不强求)
- 不出现任何 DMCA / 侵权投诉

## 6. 非功能需求

| 维度 | 指标 |
|---|---|
| 延迟(端到端首音) | 目标 1.5s,可接受 2.5s,超标报警 |
| 延迟(barge-in 响应) | 目标 150ms,可接受 300ms |
| 可用性 | 展位连续运行 4 小时不崩溃 |
| 降级 | 三级 TTS 降级 + 预录台词兜底 |
| 合规 | 见 [compliance.md](./compliance.md) |
| 隐私 | 观众语音不落盘、不上传(ADR-0009) |
| 预算 | 硬件 ≤ ¥500,LLM API ≤ ¥50/天 |
| 工期 | Phase 0-8 完成 ≤ 17 天 |

## 7. 约束

### 7.1 时间
- 目标展出时间:校园嘉年华当天(日期 TBD)
- 从今天起反推:**17 天开发 + 3 天缓冲 = 3 周总窗口**

### 7.2 人力
- **1 人独立开发**(即作者),学长仅提供服务器资源
- 无专职美术 / 无专职测试 / 无专职运营

### 7.3 预算
- 硬件 < ¥500
- 云服务(LLM API)展位日 ¥20-50
- 学长服务器资源 = 0(已有)

### 7.4 合规(见 compliance.md)
- 非商用、非盈利
- 不使用电影原声、原画、原曲
- 开源版无未成年角色
- MOSS 不用刘琮声纹

### 7.5 技术
- 黑屏 + 纯语音(硬性,不可破)
- 2 分钟 (硬性,不可长不可短)
- 1 对 1 (硬性,不做多人)

## 8. 风险与开放问题

### 8.1 风险(已有缓解)

| 风险 | 缓解 |
|---|---|
| 展位 WiFi 不稳 | 4G 热点备网 + 三级降级 |
| 学长服务器挂 | 本地 TTS fallback + 预录库 |
| LLM 人设跑偏 | JSON schema + few-shot + 引擎兜底 |
| 观众身体不适 | F10 中止键 + 情绪基线上限 |
| 合规投诉 | README 声明 + 7 天下架预案 |

### 8.2 开放问题(待决)
